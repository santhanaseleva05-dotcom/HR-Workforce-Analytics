# HR Workforce, Performance & Compensation Analytics

## Project Overview
An end-to-end HR analytics project using MySQL and Power BI to analyze workforce distribution, employee retention, compensation, performance, and employee satisfaction.

The project uses the HRDataset_v14 dataset, containing 311 employee records and 36 columns.

## Tools & Technologies
- **MySQL** — Data analysis, SQL queries, and relational data modeling
- **Microsoft Excel** — Data cleaning and preparation
- **Power BI** — Interactive dashboards and data visualization

## Data Preparation
The dataset was reviewed and cleaned in Excel. Data preparation included checking employee IDs, standardizing text values, reviewing date formats, validating Yes/No values, and checking numeric fields.

## Database Design
The project uses a dimensional data model with dimension tables and a fact table to organize employee, department, position, date, and workforce-related information.

## SQL Analysis
The analysis covers four key areas:

- **Workforce Analysis** — Employee counts and workforce distribution
- **Retention & Turnover** — Active employees, terminated employees, and termination patterns
- **Compensation Analysis** — Salary-related analysis
- **Performance & Experience** — Performance scores, engagement, and employee satisfaction

## Key Findings
- Total employee records analyzed: **311**
- Active employees: **207**
- Terminated employees: **104**
- Production department employees: **209**
- Production Technician I employees: **137**
- Production department terminations: **83 (39.71%)**

## Power BI Dashboard
The dashboard presents workforce metrics, employee distribution, turnover patterns, compensation, and performance-related insights.
